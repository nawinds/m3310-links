# Инструкция по добавлению дедлайнов и тестов

Все даты дедлайнов и тестов указаны в формате JSON. Пожалуйста, добавляйте дедлайны по образцу тех, которые уже есть.

Удалять старые дедлайны не нужно.

:::warning
<h2>Основные правила</h2>

1. Строго соблюдайте формат времени, смотрите на существующие дедлайны как на образец;
2. Чтобы добавить предстоящий тест, добавьте в начало названия дедлайна "[Тест] ". Бот определяет тесты по этому префиксу;
3. Указывайте названия дедлайнов в таком формате: `<Предмет>: <Тип работы (Лаба, ДЗ, ...)> №<Номер>. <Название работы (если есть)> (<Преподаватель или поток>)` (например: `Компиляторы: Лаба №1. Линковка (Булычев)`);
4. Указывайте названия тестов в таком формате: `[Тест] <Предмет>: Тест на <Тема теста>` (например: [Тест] Алгосы: Тест на сортировки). Для тестов префикс `[Тест]`. Также есть префиксы `[Лекция]`, `[Защита]`, `[Экзамен]`, `[Консультация]`;
5. Указывайте название предмета в той же форме, что и в остальных дедлайнах (ML, Сети, Веб, Философия, Компиляторы, Данные, ...)
:::

<h2>TL;DR</h2>

Следуйте образцу, приводите дедлайны к единой форме, формат `<Предмет>: <Тип работы (Лаба, ДЗ, ...)> №<Номер>. <Название работы (если есть)> (<Преподаватель или поток>)`.
Для тестов префикс `[Тест]`. Также есть префиксы `[Лекция]`, `[Защита]`, `[Экзамен]`, `[Консультация]`.
Для получения прямого доступа к редактированию дедлайнов и тестов (без форков и пулл-реквестов), отправьте свой GitHub аккаунт [@nawinds](https://t.me/nawinds).
